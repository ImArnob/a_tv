# 📺 Live TV App

A modern and responsive **Flutter Live TV streaming application** built with a clean UI, category-based filtering, live video playback, and smooth animations.  
The app fetches live TV channels from an M3U playlist API and allows users to browse, search, filter, and watch live channels with a professional video player experience.

---

## ✨ Features

- 📡 Live TV channel streaming
- 🎬 Chewie video player integration
- ▶️ Custom live TV play/pause controls
- 🔄 Live stream reconnect on resume
- 🔍 Search channels by name or category
- 📂 Category-based channel filtering
- 🧭 Modern drawer navigation
- 🖼️ Cached network channel logos
- 📱 Fully responsive grid layout
- 🎨 Dark modern UI with red accent theme
- ⚡ Smooth card animations
- 🔃 Pull-to-refresh channel list
- ❌ Loading and error handling
- 🖥️ Landscape video support
- 📺 Fullscreen video mode
